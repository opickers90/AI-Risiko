    Gambar 1: Peta earthquake ruptures skenario kejadian gempa

    Stochastic event set calculator menggunakan model sumber (source model) dan logic tree (source model) untuk menghitung earthquake rupture forecast (ERF). ERF menghasilkan event set yaitu list dari rupture yang mungkin terjadi dari seluruh sumber gempa beserta probabilitas terjadinya. Hasilnya diperoleh 11.672.993 ruptures yang merupakan rupture dari event set.

    GMPE logic tree menggunakan weighted mean dari tingkat aktivitas gempa untuk masing-masing dari tiga model sumber tersebut. Faktor amplifikasi tanah dimodelkan dengan tiga proksi: topografi, VS30 (dari kemiringan topografi, menggunakan metode (Allen, Trevor I; Wald, 2007)) dan unit/ umur geologi.

    Ketidakpastian epistemik dalam model sumber gempa dan ground motion diperbanyak (propagated) melalui penggunaan pohon logika (Pagani dkk., 2014). Jumlah ini cukup untuk kajian risiko skalan nasional. Katalog stokastik 1.000 tahun, dan ground motion fields untuk setiap kejadian di stochastic catalogue, dihasilkan untuk masing-masing cabang pohon logika sampel (juga disebut sebagai 'realization' ), dengan mempertimbangkan hanya gempa bumi dengan magnitudo di atas 5,5 dan jarak dalam 300 km dari episenter.
